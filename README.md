# Homebrew tap for Ledge

[Ledge](https://ledgeapp.dev) turns the notch on a MacBook into a small live status area. Free and open source.

```sh
brew install --cask egemertbalcik/tap/ledge
```

Needs a MacBook with a notch and macOS 26 or later. Ledge updates itself with Sparkle after that.

Source: https://github.com/egemertbalcik/Ledge
